# 手谈死活题格式

这里收录的是手谈自带的轻量入门题库。当前只接收贡献者原创、可按仓库根目录 MIT
许可证发布的内容，不复制书籍、课程或其他题库的图形与讲解。

## Manifest

`manifest.json` 负责题目顺序和界面文案。每题需要以下字段：

- `id`、`file`：稳定且唯一的标识与当前目录内的 SGF 文件名；
- `title`、`level`、`tags`、`goal`：面向新手的中文简短说明；
- `hints`：依次为 `text`、`region`、`answer` 三级中文提示；
- `title_en`、`goal_en`、`hints_en`：与中文内容及提示坐标一致的英文版本；
- `author`、`source`、`license`：内容来源与许可。

坐标使用 SGF 左上角原点，例如 `aa`。首版练习盘固定为 9 路。

## SGF 子集

解析器聚焦 FF[4] 中练习所需的部分：

- 根节点：`GM[1]FF[4]CA[UTF-8]SZ[9]PL[...]AB[...]AW[...]C[...]`；
- 变化节点：`B[...]` 或 `W[...]`，可带 `TE[1]`、`BM[1]` 和 `C[...]`；
- 终点：`HO[S]` 表示成功，`HO[F]` 表示失败，`HO[C]` 表示完成。

每题至少要有一条成功变化和一条失败变化。自动应手写在用户着法之后，直到再次轮到
解题方或到达终点。首版不收录劫与双活，避免练习判定依赖额外规则状态。

## 验证

在仓库根目录运行：

```powershell
node --test tests/practice_state.test.mjs tests/problem_pack.test.mjs
```

测试会检查元数据、坐标、根摆子重叠、合法落子、提子、自杀、成功/失败分支，并用
应用实际使用的状态机逐题走通答案。

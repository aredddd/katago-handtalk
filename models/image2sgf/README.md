# Screenshot recognition weights

Place these two files in this directory before running `setup-local.ps1`:

- `board.pth`
- `stone.pth`

The upstream release page is
[noword/image2sgf releases](https://github.com/noword/image2sgf/releases), but
the project did not publish an explicit source or model license as of
2026-08-28. The large weight files are intentionally excluded from Git. Only
use locally obtained copies when you have the right to do so, and do not
redistribute them with this project. See
[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).

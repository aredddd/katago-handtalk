# Optional screenshot-recognition weights

Place compatible user-supplied files here before enabling screenshot
recognition:

- `board.pth`
- `stone.pth`

The files are not part of this repository or its releases and are ignored by
Git. Obtain them only from a source you trust and have the right to use. The
older `models/image2sgf/` location remains a fallback for existing local
installations.

See [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) for the distribution
boundary and third-party attribution.
